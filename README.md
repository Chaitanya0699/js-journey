## ✍️ The Note-Taking Golden Rules

1. **Own words only**: Never copy-paste text from tutorials, documentation, or AI. Rephrase it in your own voice.
2. **The 3-Part Formula**: For every topic note, always include:
   - **What it is** (concise definition)
   - **A tiny example** (minimal working snippet)
   - **One common mistake** (pitfall + fix)
3. **Always log mistakes**: Every error is free knowledge. Log what happened and the root cause in [mistakes.md](file:///d:/Portfolio/js-journey/mistakes.md).
4. **Explain it simply**: Finish each day with a quick plain-English analogy in [explain-it.md](file:///d:/Portfolio/js-journey/explain-it.md).
5. **Sunday Review**: Re-read [mistakes.md](file:///d:/Portfolio/js-journey/mistakes.md) every Sunday to cement lessons learned.
